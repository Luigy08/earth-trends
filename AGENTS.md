# Project instructions

- For every request in this repository, load and follow [`.agents/skills/earth-system-trend-detective/SKILL.md`](.agents/skills/earth-system-trend-detective/SKILL.md). It preserves the NASA Space Apps challenge context, science requirements, and agreed POC scope across sessions.
- Follow SOLID. Reuse common components instead of duplicating code. Preserve existing function and variable names.
- Before adding a type/interface, inspect existing `.types.ts` files and shared contracts. Place types, constants, styles, and resolvers in their corresponding files where appropriate.
- Prefer MUI components where practical. Keep files under 1,000 lines when practical.
- Do not add or run tests unless the user asks. Run a build/type-check only when it is useful to verify a requested change.
- The product interface is English. The user may communicate in Spanish; respond in the language appropriate to their message.
- Keep responses concise and focus on requested work; provide explanations only when requested or necessary to report a blocker or deployment status.
